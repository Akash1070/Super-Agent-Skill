## ⚡ 5-Second 1-Click Setup

No complex build steps. Paste this into your IDE's `mcp_config.json` and you're good to go:

```json
{
  "mcpServers": {
    "super-agent-skill": {
      "command": "npx",
      "args": [
        "-y",
        "github:Akash1070/Super-Agent-Skill"
      ]
    }
  }
}
```
