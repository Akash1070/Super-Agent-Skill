## ⚡ 1-Click Setup for ANY AI Agent & IDE

No complex terminal installation required! Simply copy and paste the JSON block below into your IDE's `mcp_config.json`:

```json
{
  "mcpServers": {
    "super-agent-skill": {
      "command": "npx",
      "args": [
        "-y",
        "github:Akash1070/Super-Agent-Skill"
      ]
    }
  }
}
```
